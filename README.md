# 🦴 Skeleton-v OSINT ToolKit

**Skeleton-v OSINT ToolKit** — компактный CLI-инструментарий для OSINT-исследований и анализа информации из открытых источников.

### ⚡ Features

* **[1] Domain Recon** — сбор и анализ информации о домене
* **[2] DNS Enumeration** — перечисление DNS-записей
* **[3] Subdomain OSINT** — поиск и анализ поддоменов
* **[4] IP Intelligence** — получение информации об IP-адресах
* **[5] URL Analyzer** — анализ URL и связанных данных
* **[6] Username Search** — поиск username по открытым источникам
* **[7] Username OSINT** — OSINT-анализ username
* **[8] Email OSINT** — анализ публичной информации, связанной с email
* **[9] File Metadata** — извлечение метаданных из файлов
* **[10] HTTP Headers** — анализ HTTP-заголовков
* **[11] All Modules CLI** — запуск всех доступных модулей из CLI

> Built for researchers, cybersecurity enthusiasts and OSINT practitioners.

### ⚠️ Disclaimer

Skeleton-v предназначен для образовательных, исследовательских и легальных целей. Используйте инструмент ответственно и только в рамках применимого законодательства.
